\# AI Assistant



Интеллектуальный чат-бот на базе архитектуры RAG (Retrieval-Augmented Generation), предназначенный для ответов на вопросы пользователей исключительно в рамках базы знаний. Проект реализует полный цикл: от векторного поиска релевантного контекста до потоковой генерации ответа через локально развёрнутую языковую модель.



\## Возможности



\- Поиск ответов по базе знаний с использованием семантического поиска (векторные эмбеддинги).

\- Потоковая генерация ответов (Server-Sent Events) для отображения текста в реальном времени.

\- Ограничение частоты запросов (rate limiting) для защиты от перегрузки.

\- Многоуровневая защита от инъекций промптов и XSS-атак.

\- Автоматическая отмена генерации при отключении клиента для экономии ресурсов.

\- Отображение источника ответа со ссылкой на соответствующий вопрос FAQ.

\- Подключаемый JavaScript-виджет с адаптивным интерфейсом.

\- Полная контейнеризация через Docker Compose.



\## Технологический стек



| Компонент | Технология |

|-----------|------------|

| Backend | Python 3.11, FastAPI |

| LLM | Ollama, Qwen 3 (14B) |

| Векторная база данных | ChromaDB |

| Модель эмбеддингов | sentence-transformers (`intfloat/multilingual-e5-large`) |

| Протокол стриминга | Server-Sent Events (SSE) |

| Frontend | HTML, CSS, JavaScript (без сторонних фреймворков) |

| Контейнеризация | Docker, Docker Compose |

| Логирование | Python `logging` с ротацией файлов (JSONL) |



\## Архитектура



Проект построен по принципу разделения ответственности (Separation of Concerns).



```

┌─────────────────┐      ┌──────────────────┐      ┌─────────────┐

│   Frontend      │ SSE  │   Backend API    │      │   Ollama    │

│   (widget.js)   │ ───► │   (FastAPI)      │ ───► │  (Qwen 3)   │

└─────────────────┘      └──────────────────┘      └─────────────┘

&#x20;                               │

&#x20;                               ▼

&#x20;                        ┌──────────────┐

&#x20;                        │   ChromaDB   │

&#x20;                        │ (Vector DB)  │

&#x20;                        └──────────────┘

```



\### Компоненты



\- \*\*`main.py`\*\* — точка входа приложения. Отвечает за настройку FastAPI, middleware (CORS), rate limiting, обработку HTTP-запросов и SSE-стриминг.

\- \*\*`rag\_agent.py`\*\* — модуль бизнес-логики RAG. Содержит класс `RAGAgent`, инкапсулирующий работу с эмбеддингами, векторной базой данных, формирование промптов и генерацию ответов.

\- \*\*`logger\_setup.py`\*\* — модуль логирования. Реализует запись взаимодействий в формате JSONL с автоматической ротацией файлов.

\- \*\*`faq.json`\*\* — база знаний, содержащая вопросы, ответы и ссылки на источники.

\- \*\*`widget.js`\*\* — подключаемый JavaScript-виджет чата, предоставляющий единый API инициализации (`AI.init()`).

\## Установка и запуск



\### 1. Клонирование репозитория



Для клонирования репозитория и перехода в директорию проекта необходимо выполнить:



```bash

git clone <repository-url>

cd ai-assistant

```



\### 2. Запуск сервисов



Для сборки и запуска всех сервисов требуется выполнить команду:



```bash

docker compose up --build

```



Команда выполняет следующие действия:

\- Сборка Docker-образа для backend-приложения.

\- Запуск контейнера Ollama с языковой моделью.

\- Ожидание готовности Ollama (через healthcheck).

\- Запуск backend-приложения и инициализация базы знаний из `faq.json`.



\### 3. Загрузка модели



После первого запуска требуется загрузить модель в Ollama. Для этого в отдельном терминале необходимо выполнить:



```bash

docker exec -it ai-assistant-ollama ollama pull qwen3:14b

```



После завершения загрузки требуется перезапустить backend:



```bash

docker compose restart backend

```



\### 4. Использование



Для взаимодействия с чат-ботом необходимо открыть файл `index.html` в браузере.



Для интеграции виджета на сторонний сайт требуется подключить `widget.js` и вызвать инициализацию:



```html

<script src="widget.js"></script>

<script>

&#x20;   AI.init({

&#x20;       apiUrl: "http://<host>:8000/chat"

&#x20;   });

</script>

```



\## API



\### `POST /chat`



Принимает сообщение пользователя и возвращает ответ в виде SSE-потока.



\*\*Ограничение:\*\* 5 запросов в минуту с одного IP-адреса.



\*\*Запрос:\*\*



```http

POST /chat HTTP/1.1

Content-Type: application/json



{

&#x20;   "message": "Как отменить подписку?"

}

```



\*\*Ответ (SSE-поток):\*\*



```

data: {"text": "Чтобы"}

data: {"text": " отменить"}

data: {"text": " подписку..."}

data: \[DONE]

```



\*\*Коды состояния:\*\*



| Код | Описание |

|-----|----------|

| 200 | Успешный ответ (SSE-поток) |

| 400 | Некорректное сообщение (пустое или длиннее 1000 символов) |

| 429 | Превышен лимит запросов |

| 500 | Внутренняя ошибка сервера |



\## Безопасность



Проект реализует многоуровневую систему защиты:



1\. \*\*Защита от Prompt Injection.\*\* Фильтрация подозрительных паттернов во входящих запросах. Изоляция контекста базы знаний через разделители `<CONTEXT>` с явными инструкциями для модели.



2\. \*\*Защита от DoS-атак.\*\* Rate limiting (5 запросов в минуту). Проверка `request.is\_disconnected()` позволяет немедленно прекратить генерацию при отключении клиента, что предотвращает расходование вычислительных ресурсов на необслуживаемые запросы.



3\. \*\*Защита от XSS.\*\* Виджет использует `textContent` вместо `innerHTML` при рендеринге сообщений, что исключает выполнение внедрённого вредоносного кода.



4\. \*\*Валидация источников.\*\* Ссылка на источник отображается только в случае, если ответ модели не содержит признаков отказа и имеет достаточную содержательную длину.



5\. \*\*Изоляция сервисов.\*\* Каждый компонент (backend, Ollama, база данных) работает в отдельном Docker-контейнере с собственной файловой системой и сетью.



\## Тестирование



Качество ответов проверяется на тестовой выборке из 21 вопроса, включающей:

\- Вопросы, соответствующие тематике базы знаний.

\- Идентификационные вопросы (о модели, инструкциях).

\- Вопросы, не относящиеся к тематике компании.



Критерий приёмки: не менее 80% корректных ответов на тестовой выборке.



\## Хранилища данных



| Путь | Назначение |

|------|------------|

| `faq.json` | Исходная база знаний (вопросы, ответы, URL источников) |
